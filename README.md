# Credit Desk — Putuskan seperti pemberi pinjaman

**Ukur. Nilai. Putuskan.**

Kursus dan simulator keputusan kredit: menganalisis peminjam, merancang covenant, dan memantau kredit bermasalah — dari sudut pandang pemberi pinjaman.

**Live:** https://credit-desk-afy.pages.dev/

## Isi

- **K1–K6** — fondasi analisis kredit (laporan keuangan, rasio, arus kas, agunan, karakter, kondisi)
- **Credit Decision Simulator** (flagship) — 3 peminjam ilustratif, lulus ≥70%
- **Covenant Designer** — merancang covenant keuangan
- **Monitoring Drill** — latihan pemantauan kredit

## Teknologi

Static site — HTML/CSS/JS murni, deploy via Cloudflare Pages. Progres tersimpan di localStorage.
